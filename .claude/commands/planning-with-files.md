# Planning with Files 실행

다음 작업에 대해 Manus 스타일 파일 기반 계획을 시작하세요: $ARGUMENTS

## 3-File 패턴 적용:
1. `task_plan.md` - 페이즈와 진행 상황 추적
2. `notes.md` - 연구 결과 및 발견 사항 저장
3. `[deliverable].md` - 최종 산출물

## 핵심 규칙:
- 결정 전 항상 `task_plan.md` 읽기 (목표 refresh)
- 각 페이즈 완료 후 즉시 체크박스 업데이트
- 오류는 숨기지 말고 기록
